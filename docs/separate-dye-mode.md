# 分体染色模式说明

## 功能概述

`AvatarGifTool` 的模式列表现在包含：

- 普通模式
- 整体染色模式（原“染色模式”）
- 精确染色模式
- 分体染色模式

分体染色模式使用与精确染色模式相同的染色参数和动作导出方式，区别在于每个 Gear 可以保存一套独立的染色数据。

每个 Gear 保存的参数包括：

- 色系
- 颜色 / 色相
- 饱和度偏移
- 亮度偏移

## 操作流程

1. 选择 `分体染色模式`。
2. 在 `Gear` 输入框填写一个装备外观的 ID 或名称。
3. 调整色系、颜色、饱和度和亮度。
4. 点击 `保存当前 Gear 染色`。
5. 保存成功后：
   - 当前 Gear 的参数保存为一个以外观名显示的小按钮；
   - `Gear` 输入框自动清空；
   - 可以继续填写其他 Gear 并重复保存。
6. 点击已保存的小按钮，会回填对应 Gear 及其保存时的全部染色参数。
7. 对同一件外观再次保存时，会更新原来的小按钮，不会新增重复按钮。
8. 点击 `导出` 时，所有已保存 Gear 会分别应用自己的染色参数，并使用普通模式的动作列表生成 GIF。

如果当前 `Gear` 输入框仍有未保存内容，预览和导出会临时采用当前参数；保存后则以按钮中保存的数据为准。

## 限制与回退

- 分体染色每次只能保存一个 Gear；填写多个 Gear 后点击保存会提示先改为单个外观。
- 分体染色模式至少需要保存一个 Gear 才能导出。
- 保存和参数回填需要先加载 `Base.wz`。
- 保存数据会写入程序同目录的配置文件，重启后仍然保留。

## 配置数据

配置文件新增 `SeparateDyeItems` 数组：

```json
{
  "SeparateDyeItems": [
    {
      "GearId": 1053345,
      "GearName": "红色冒险岛服",
      "PrismType": 1,
      "Hue": 30,
      "SaturationOffset": 12,
      "BrightnessOffset": -6
    }
  ]
}
```

同一 `GearId` 在规范化时会去重，参数范围也会被限制到界面允许的范围内。

## Gear 名称反向解析

Gear 输入框会把成功解析的 ID 显示为外观名，并在内部保存“显示名 -> ID”的映射。反向解析现在会：

- 优先使用当前输入框的显示名映射；
- 只接受 Gear 类型的结果，避免同名脸型、发型或道具误匹配；
- 在同名装备存在多个 ID 时，使用稳定的 ID 顺序，并支持 `名称#2`、`名称#3` 这类重复名称显示后缀；
- 对未进入角色外观索引、但存在于 String/Item 数据里的装备名称增加补充查找。

这修复了染色模式下名称已显示、但校验或导出时无法再映射回 Gear ID 的问题。

## 历史搭配清空

`历史搭配` 标题右侧新增 `清空` 小按钮，点击后会立即移除当前保存的全部历史搭配，并同步写入配置文件。
